# Arihant Enterprises — GitHub Pages site

This folder is ready to publish as a GitHub Pages website. It uses only HTML and CSS, so no installation or build step is needed.

## Publish it on GitHub Pages

1. Sign in to the GitHub account **digitalarihantent-hub**.
2. Create a new public repository called `arihanth-enterprises` (or any preferred name).
3. Upload all the files from this folder, keeping `index.html` in the repository root.
4. In the repository, open **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**, then select the `main` branch and the `/ (root)` folder. Save.
6. GitHub will show the published address. For a repository named `arihant-enterprises`, it will be:
   `https://digitalarihantent-hub.github.io/arihant-enterprises/`

Use that final live address to create the QR code for labels. Keep the repository name unchanged after printing QR labels, so the QR link continues to work.
